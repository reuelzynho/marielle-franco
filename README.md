# Marielle — Memória, Voz e Democracia

Exposição digital educativa desenvolvida com HTML5, CSS3 e JavaScript puro para apresentação acadêmica.

## Estrutura
- `index.html`: conteúdo e estrutura semântica.
- `css/style.css`: identidade visual, layout responsivo e acessibilidade.
- `js/script.js`: menu móvel, linha do tempo, animações e progresso de leitura.
- `assets/`: espaço reservado para imagens autorizadas e outros arquivos estáticos.

## Como executar
1. Extraia a pasta do ZIP.
2. Abra `index.html` em um navegador atualizado.
3. Para editar, abra a pasta no Visual Studio Code.

Não é necessário instalar dependências nem iniciar servidor.

## Antes da apresentação
- Preencha a identificação acadêmica: nome, campus, curso/turma, disciplina e orientação, conforme solicitado pelo professor.
- Se inserir fotografias, confirme licença ou autorização de uso, inclua crédito e texto alternativo (alt).
- Confira se os links externos continuam ativos e se a situação judicial teve atualização posterior.
- Teste navegação por teclado, zoom, contraste e visualização em celular.
- Faça uma apresentação de teste sem internet: a fonte Google Fonts pode não carregar, mas o site mantém fontes alternativas.

## Revisão histórica
A seção judicial diferencia os crimes atribuídos aos réus na decisão da Primeira Turma do STF. A condenação de todos os cinco réus não significa que todos tenham sido condenados pelos homicídios: as condenações foram por crimes diferentes, conforme a decisão oficial.

## Tecnologias
HTML5, CSS3 e JavaScript (ES6+). Não há bibliotecas ou frameworks obrigatórios.
